# Nsight Compute profiles (T1.9) — pending

This file is generated by `bench/profile_ncu.sh` on a counter-capable RTX 3090 and is
**not yet populated**. The development box denies access to GPU performance counters
(`RmProfilingAdminOnly=1`, every `ncu` invocation returns `ERR_NVGPUCTRPERM`), so the
counter-derived figures — SM speed-of-light, memory speed-of-light, achieved occupancy,
DRAM throughput and shared-memory bank conflicts — cannot be measured there and are
deliberately absent rather than estimated.

What *was* measurable on the development box is in **[analysis.md](analysis.md)**: kernel
resource footprints, theoretical occupancy from the CUDA occupancy API, an analytical
roofline built from CUDA-event timings, and Nsight Systems timelines.

To populate this file:

```bash
bash bench/profile_ncu.sh
```

It captures `ncu --set full` on prefill (N=2048, causal, B=4, H=12) and decode (S=1024),
writes `ncu_prefill.ncu-rep` and `ncu_decode.ncu-rep` beside this file, and extracts the
required metrics here. It refuses to run, with instructions, on a machine whose driver
restricts counters.
